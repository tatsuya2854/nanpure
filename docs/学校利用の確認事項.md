# 学校で使う前に確認すること（個人情報・児童の記録）
※ これは技術側の整理で、法的な助言ではない。最終判断は学校・教育委員会のルールに従う。

## このアプリが保存するもの
| 場所 | 内容 | 保存期間 |
|---|---|---|
| 児童の端末（ブラウザ） | ニックネーム、自己ベスト、称号、途中保存、匿名ID | 端末に残る（「きろくをぜんぶけす」で削除） |
| サーバー（今日のチャレンジ） | 匿名IDの**ハッシュ**、ニックネーム、タイム、ヒント回数 | 7日で自動削除 |
| サーバー（クラスチャレンジ） | 同上＋チャレンジ名 | 30日で自動削除。先生がいつでも手動削除可 |
| サーバー（回数制限用） | IPアドレスの**ハッシュ**と回数 | 数分〜1時間で削除 |

収集しない: 本名、メール、電話、住所、学校名、クラス名（チャレンジ名は先生が自由に付ける。個人が特定される名前は付けないよう周知する）。広告・課金・チャット・外部送信なし。

## 学校側で確認・判断してほしいこと
1. **ニックネームのルール**を児童に周知する（本名・あだ名で個人が分かるものは使わない）。自動フィルターは基本的なもので完全ではない。
2. **学校の情報セキュリティ方針**で、外部のWebサービス（Cloudflare上で動作、データは米国等を含む海外のデータセンターに置かれ得る）の利用が許されるか。
3. 保護者への周知・同意が必要か（個人情報を取得しない設計だが、ニックネームとタイムは「記録」にあたる）。
4. **先生用の合言葉**の管理者を決める（複数の先生で共有。漏れたら変更する）。生徒に教えない。
5. 先生がクラス終了後に記録を削除する運用（結果画面の「記録を削除する」）。
6. 端末を共有する場合、前の児童の途中保存・ニックネームが残る。**児童ごとの端末**か、終わるたび「きろくをぜんぶけす」を使う。
7. 不適切なニックネームが出た場合の対応（先生がチャレンジを削除→作り直し）。

## 不正対策の限界（明示）
- 同じ児童が別端末・ブラウザ保存データの削除で**別人として再参加**することは完全には防げない（匿名・個人情報なしの設計上の制約）。参加人数が実人数より増えることがある。
- ブラウザの開発者ツールに詳しい児童が、問題の解答を自分で計算して提出することは理論上可能（解答は端末側でも再現できるため）。サーバーは、盤面の正しさ・現実的なタイム・ヒント回数の整合を検査するが、「自力で解いたか」までは証明できない。
- 先生モードの合言葉は1つ。複数の先生は同じ管理画面を共有し、互いのチャレンジも見える。
