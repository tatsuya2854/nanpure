# 小学生による実利用テスト チェックリスト
※ 実際の児童によるテストは**まだ実施していません**。実施したら結果を下の表に記入する。

進め方: 児童に説明せず端末を渡し、大人は**見るだけ**（聞かれるまで助けない）。1人5分。タブレット（iPad・Chromebook）で。

| # | 観察すること | 判定の目安 | 結果 |
|---|---|---|---|
| 1 | 説明なしでゲームを開始できたか | 10秒以内に問題が出る | |
| 2 | 数字の入力方法がわかったか | マスを押す→数字ボタン、が自力でできる | |
| 3 | ヒントの意味がわかったか | 💡の回数が減ることを理解し、使い方を言える | |
| 4 | 間違いに気づけたか | ✕マークと斜線で気づく | |
| 5 | 途中で困らなかったか | 止まった場所・聞かれた質問を記録 | |
| 6 | 「もどす」「メモ」を使えたか | 使わなくてもよい。使えた/気づかなかった | |
| 7 | 5分間 楽しめたか | 飽きて別のことをしなかった | |
| 8 | もう一度遊びたいと言ったか | 「もう1回」と言った/言わなかった | |
| 9 | 4×4のチュートリアルが理解できたか | 4手で完了できる | |
| 10 | 文字が読めたか（ひらがな中心） | 読めない語を記録 | |

学年別に見ること: 3年（ひらがな・操作）／4〜6年（9×9の難しさ・飽き）。
先生側（別途）: 30秒以内にチャレンジを作成できたか／コードとQRを児童に共有できたか／結果が見やすいか。
